# 用 Flutter 重建 app:目标安卓,在 WSL2 里通过无线调试开发

Status: accepted

## 背景
现有 app 是一个单文件 vanilla JS 的网页 PWA(尤克里里弹唱练习器),已经能跑、能装到手机桌面。用户(编程初学者)想在此基础上"升级到 Flutter"。

## 决定
用 Flutter(Dart)重新实现这个 app;**目标平台先定为安卓**;开发环境放在 **WSL2** 里,通过手机的**无线调试(Android 11+)**连接真机,不走 USB 穿透。网页版(`index.html` 等)暂时保留,不删除。

## 为什么
- "升级到 Flutter"的真实动机是**学习 Flutter**,不是网页版有解决不了的问题——这是"重写"能成立的唯一理由。
- 安卓(而非先做 Flutter Web)是用户的明确选择;能在自己手机上跑,对学习是强反馈。用户有一台可连接的安卓真机,这是 WSL2 上做安卓开发最顺的前提。
- 选 WSL2 而非 Windows 侧:项目与 AI 助手都在 WSL,环境统一、可直接代跑命令;用无线调试绕开 WSL2 最头疼的 USB 穿透问题。

## 考虑过的备选
- **保持网页 PWA / 不重写**:能满足"用"的需求,但达不到"学 Flutter"的目标。网页版保留作参考。
- **Flutter Web 先行**:设置门槛最低、最适合纯学习,但用户明确想上手机。作为"安卓环境卡住时的兜底"保留。
- **Windows 侧 + Android Studio + USB**:官方最顺、USB 免折腾,但脱离 WSL 环境,AI 助手无法直接代跑命令。

## 后果
- 初次安卓构建要下载 Gradle / Android SDK 组件,一次性较慢。
- 无线调试偶尔掉线,重连即可;真卡住可退回 `usbipd-win` 或临时切 Web。
- 同一份 Flutter 代码以后可基本不改地编译到 iOS(需 Mac)/ Web / 桌面。
- 网页版暂时保留,不删,作为对照参考。
